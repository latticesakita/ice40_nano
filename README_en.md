# iCE40_nano

This project implements a RISC-V processor (nano core) on the iCE40 Ultra Plus FPGA using Lattice Propel.


Lattice Propel を使用して RISC-V プロセッサ(nano core)を iCE40 Ultra Plus FPGA に実装したプロジェクトです。

---

## 🚀 Project Overview


This project aims to build a RISC-V based SoC on the low-power, compact **iCE40 Ultra Plus** FPGA. It utilizes Lattice Propel for integrated hardware and software development. For reference, it includes an initialization routine for an image sensor.
The iCE40_nano project focuses on compactness rather than performance. Compared to the iCE40_SM project, its performance is lower, but it uses approximately 800 fewer LUTs, making it easier to add other custom logic.


---

## 🔧 Technologies Used


- FPGA: Lattice iCE40 Ultra Plus
- Development Tools:
  - Lattice Propel (Builder: `ice40_nano.sbx`)
  - Lattice Radiant (Project: `ice40_nano.rdf`)
- Processor: RISC-V
- HDL: Verilog
- Accessing iCE40UP Hardened IP from RISC-V
- RISC-V runs on SPSRAM of iCE40UP
- IP Packaging: `.ipk` (using Propel's `ippack` tool)

## 🛠️ Build Instructions
Please install Python on your system.
The mem file generated by Propel is converted to a binary file.


1. Edit C source code by launching Lattice Propel and opening `ws`
2. After post-build, the mem file is automatically copied to the `tb` folder.
3. Run simulation by executing `tb/tb.spf` script from Radiant.
4. Launch Propel Builder and load `ice40_nano/ice40_nano.sbx`
5. If changes are made in Builder, launching Radiant from Builder will reflect those changes.
6. Writing to SPI Flash
7. Address: 0x000000 → `impl_1/ice40_sm_impl_1.bin`
8. Address: 0x030000 → `propel_ws/ice40_nano/Debug/ice40_nano_Code_BE.bin`


The target evaluation board is the Upduino board.
